# Roadmap

## Phase 0 — Governance and target lock

- freeze canonical problem authority;
- establish claim levels;
- establish experiment/reproducibility contracts;
- establish machine-readable agent rules;
- establish licensing and citation metadata.

## Phase 1 — Known-boundary reconstruction

- reproduce the precise theorem landscape relevant to regularity and breakdown;
- build a structured literature map;
- identify proof barriers and common invalid proof patterns;
- implement baseline identities and diagnostic tests.

## Phase 2 — Deterministic PDE laboratory

- implement reference solvers and exact experiment manifests;
- add divergence, energy, enstrophy and vorticity diagnostics;
- add spectral and scale-local diagnostics;
- add resolution, precision and timestep sweeps;
- distinguish numerical instability from candidate continuum behavior.

## Phase 3 — Competing mechanism search

### Regularity track

Search for sharpened a priori bounds, monotone/coercive quantities, geometric depletion mechanisms, continuation criteria or concentration exclusions.

### Breakdown track

Search for admissible initial-data families, concentration mechanisms, scaling scenarios or rigorous reductions that could force loss of regularity.

## Phase 4 — Proof extraction

Promote only precise candidate lemmas. Attempt analytic proof, symbolic checking, interval methods or proof-assistant formalization where each method is appropriate.

## Phase 5 — Adversarial review

Try to break every promoted result with edge cases, scaling checks, hidden assumptions, known theorems, alternate discretizations and independent reviewers.

## Phase 6 — Publication/archive

Only after the publication gate: freeze exact commit/tag, generate citation metadata, archive artifacts, and publish wording that matches the actual claim level.
