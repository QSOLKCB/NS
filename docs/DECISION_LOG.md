# Decision Log

Use this file for durable project-level decisions that change how research is interpreted, reproduced or published.

## D-0001 — Two-track research program

Status: accepted

Decision: investigate global regularity and finite-time breakdown in parallel; neither direction is privileged by project policy.

Reason: the Millennium problem can be resolved by an admissible proof on either side of the official alternatives.

## D-0002 — Numerical evidence is non-proof evidence

Status: accepted

Decision: no numerical result, regardless of resolution or apparent divergence, may be promoted directly to a continuum proof claim.

Reason: discretization, truncation, roundoff, instability and solver failure are competing explanations until rigorously excluded.

## D-0003 — Machine-readable agent authority

Status: accepted

Decision: `AGENTS.md` contains strict JSON and is validated by `AGENTS.schema.json`; agents must treat it as data, not conversational guidance.

Reason: deterministic policy parsing is preferable to prose interpretation for autonomous coding/research agents.

## D-0004 — Scope-based licensing

Status: accepted

Decision: software and machine-readable infrastructure use Apache-2.0; explicitly marked human-authored research prose/figures use CC-BY-4.0.

Reason: preserve software reuse/patent terms while making scholarly prose and figures attribution-reusable.

## D-0005 — Public solution claims require a human gate

Status: accepted

Decision: automated agents cannot assign or announce the highest claim level.

Reason: mapping a result to the official problem, novelty assessment, scholarly review and public wording require explicit accountable judgment.
