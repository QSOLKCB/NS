This repository uses an explicit scope-based licensing model.

## Apache-2.0 scope

The root `LICENSE` contains the Apache License, Version 2.0. Unless a file explicitly states otherwise, Apache-2.0 applies to:

- source code;
- tests;
- build and CI configuration;
- machine-readable schemas and manifests;
- `AGENTS.md` and `AGENTS.schema.json`;
- experiment orchestration and analysis tooling;
- configuration and reproducibility infrastructure;
- generated software documentation that is not separately marked.

SPDX identifier: `Apache-2.0`.

## CC BY 4.0 scope

Human-authored research prose, papers, reports, diagrams and figures are licensed under Creative Commons Attribution 4.0 International only when the file or containing document explicitly states:

`SPDX-License-Identifier: CC-BY-4.0`

or otherwise clearly declares CC BY 4.0.

Attribution should identify Trent Slade / QSOL-IMC, the work title when available, the source repository or DOI when available, and indicate modifications.

Canonical license: https://creativecommons.org/licenses/by/4.0/

SPDX identifier: `CC-BY-4.0`.

## Precedence

1. A valid file-level SPDX identifier or explicit license notice controls that file.
2. Otherwise the scope rules above apply.
3. Third-party material retains its original license and must be recorded with provenance.
4. Mathematical facts, equations, theorem statements and ideas may not be subject to copyright in the same manner as their particular written expression; this repository's licenses govern copyrightable material, not ownership of mathematical truth.

## No implicit relicensing

Moving a file between directories does not silently change its license. License changes must be deliberate and recorded in version control.

## Third-party intake

Do not import code, figures, datasets, text or generated assets unless their provenance and redistribution terms are known and compatible with the intended use. Record third-party notices when required.
